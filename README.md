 Magia & Linha

Site de uma loja fictícia de produtos artesanais em crochê, desenvolvido como projeto de estudo e portfólio.

Demonstração

🔗 **[Acessar o site](https://mikelly-droid.github.io/minha-loja/)**

Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Formspree
* GitHub Pages

Funcionalidades

*  Página inicial
*  Catálogo de produtos
*  Formulário de encomendas
*  Página de confirmação personalizada
*  Página sobre a loja
*  Página de depoimentos
*  Página de tutoriais
*  Layout responsivo para celular e computador

Formulário de encomendas

O projeto possui um formulário para que o cliente possa informar:

* Nome
* WhatsApp
* Instagram
* Tipo de peça
* Modelo desejado
* Cores
* Tamanho
* Prazo
* Cidade e CEP
* Observações e referências

Os dados são enviados através do **Formspree**.

Objetivo do projeto

Este projeto foi desenvolvido como prática de desenvolvimento web, aplicando conhecimentos de HTML, CSS, Bootstrap, formulários, responsividade, Git, GitHub e publicação de sites.

O que foi praticado

* Estruturação de páginas com HTML
* Estilização com CSS
* Utilização do Bootstrap
* Criação de formulários
* Navegação entre páginas
* Design responsivo
* Integração com serviço externo de formulários
* Versionamento com Git
* GitHub
* GitHub Pages
* GitHub Actions
